# Clothing Store Website

A responsive clothing store website recreated using **HTML5 and CSS3**, inspired by the W3Schools Clothing Store template.

## Project Overview

This project demonstrates how to build a clothing store layout with a sidebar navigation, promotional banner, product gallery, newsletter subscription section, and footer.

## Features

- Responsive layout for desktop and mobile screens
- Sidebar navigation with clothing categories
- Promotional hero banner
- Product grid featuring clothing items
- Product prices and sale labels
- Hover effects and responsive styling
- Newsletter subscription section
- Contact form and store information in the footer

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome icons

## How to Run the Project

1. Clone or download this repository.
2. Make sure the `style` and `images` folders contain the required files.
3. Open `index.html` in a web browser.

## Deployment

The website can be deployed as a static site using a service such as Render.

**Live Website:https://clothing-store-gyii.onrender.com

## Project Purpose

The purpose of this project is to practice semantic HTML, CSS layouts, responsive design, navigation, and styling a multi-section website without using JavaScript or CSS frameworks.
